Post-Ending Engagement

Task events after a user's first final-chapter event — past the ending there's no story left to unlock, so anything they do is practice for its own sake. A linked replay run counts in full toward the original user. Counts only; hover for the observation window, which varies hugely

Replay Users — Engagement Across Both Runs

Testers who finished the story, reset, and played the whole thing again under a new ID. Each bar stacks their first run and their replay run, so the full height is one person's total commitment. Add the links in the filters bar (replay=original). Hover for the per-run breakdown

Habits do users return at the same time on weekdays? · weekends excluded (people are busier) · anchor = first session each weekday · habit = ≥3 weekdays in a typical week, at a consistent time (within a ~4h spread) · set both in the filters bar

Habit-Forming Users

Users split by weekday routine. “Same time of day” = shows up on ≥3 weekdays in a typical week AND their start time stays within a ~4h spread. “Varied times” = shows up enough but the time drifts. “Too infrequent” = fewer than 3 weekdays in a typical week. Each bar is one content type; the three segments sum to that type’s weekday-active users — hover a segment for its count and % of that total

Timing Consistency — Distribution

Among users active ≥3 weekdays in a typical week, the spread of their weekday start times — tighter (left) is a stronger habit. Users within the ~4h window count as habitual above

When the Habit Happens
